# Student Grade Tracker

A Java-based Student Grade Tracker developed for the CodeAlpha Java Programming Internship.

## Features
- Add student details
- View student report
- Search student
- Calculate average marks
- Calculate grades
- Find highest and lowest marks
- Save student records using file handling

## Technologies Used
- Java
- OOP Concepts
- ArrayList
- File Handling

## How to Run
1. Compile: javac StudentGradeTracker.java
2. Run: java StudentGradeTracker
