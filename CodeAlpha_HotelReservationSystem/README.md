# Hotel Reservation System

A Java-based Hotel Reservation System developed for the CodeAlpha Java Programming Internship.

## Features
- View available rooms
- Book a room
- Calculate booking bill
- View all bookings
- Search booking by ID
- Cancel booking
- Save bookings using file handling

## Technologies Used
- Java
- OOP Concepts
- ArrayList
- File Handling

## How to Run
1. Compile: javac HotelReservationSystem.java
2. Run: java HotelReservationSystem
